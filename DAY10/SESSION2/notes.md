# Monotonic stack
A monotonic stack is a specialized stack data structure that enforces a strict or non-strict sorted order of its elements from bottom to top. 
# Tpyes of Monotonic Stack
    - Increasing monotonic stack
    - Decreasing monotonic stack

1. Node : Element with stores data item.
2. Edge : Connection between two nodes.
3. Root : Topmost node is root.

6. Siblings : Node having same parent.
7. Leaf node : Last node of the tree.
8. Subtree : A small part of the tree.
9. Degree of a Node : Number of children that node has.
10. Degree of a tree : Maximum degree of any nodes in the tree.
11. Path : Sequence through Edges.
